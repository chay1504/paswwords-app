Syncing the two apps

Link them once with a security key

  1. Create your vault. Open TBD Vault, tap Set up face lock and create vault and approve with your face, fingerprint or PIN.
  2. Copy the security key. On the Security code screen tap Show security key, then Copy security key.
  3. Paste it into TBD Codes. Open TBD Codes, paste the key, tap Save and set up face lock. A code appears.
  4. Open the vault. Tap Copy code, switch to TBD Vault and paste it. Make your first backup, then add your passwords.

Every day after that: face on TBD Vault, copy the code in TBD Codes, paste. The key is only needed again on a new phone.

Install

Add both apps to your home screen

They install straight from the browser. No app store, nothing to download separately. Your phone needs a screen lock (face, fingerprint or PIN).

Android (Chrome)

  1. Tap Open TBD Vault below.

  3. Come back here and do the same for TBD Codes.

iPhone (Safari)

  1. Tap Open TBD Vault below in Safari.
  2. Tap the Share button, then Add to Home Screen.

FAQ

Questions

What if I lose my phone?

Install both apps on the new phone, choose Restore from an encrypted backup in TBD Vault, pick your backup file and enter its password. Then link TBD Codes again with the security key.

Is there a password to remember?

Only your backup password, and only when you make or restore a backup. Day to day you use your face and the code.

Why two apps?

The vault will not open without a fresh code from the second app, on top of face lock. Both are on the same phone, so treat the code as an extra check rather than a separate second device.

Does it upload my passwords anywhere?

No. The apps make no network requests with your data. Everything is stored encrypted on the phone, and backups go only where you save them.

What happens if I clear my browser data?

The apps' data is removed from that phone. Restore it from your encrypted backup, which is why the vault asks for a backup before you add passwords.

How much does it cost?

Nothing. There are no accounts, subscriptions or ads.
