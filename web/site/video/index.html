TBD VAULT + TBD CODES
Two apps. One lock. Everything stays on your phone.
01 / 08

Install both apps

Download TBD Vault and TBD Codes from this page and install them on the same phone.

02 / 08

Create your vault

Open TBD Vault, tap Set up face lock and approve with your face, fingerprint or PIN.

03 / 08

Copy the security key

Tap Show security key, then Copy. You only need it once, to link the two apps.

04 / 08

Link TBD Codes

Open TBD Codes, paste the key and set up face lock. A new 8-digit code appears every few seconds.

05 / 08

Copy code, open vault

Tap Copy code in TBD Codes, switch back and paste it into TBD Vault. You are in.

06 / 08

Make your first backup

Choose a backup password and save the encrypted file somewhere safe. It is your way back on a new phone.

07 / 08

Save your passwords

Tap + Add: account, website, username and password. Copy or reveal them any time.

08 / 08

Every day

Face on TBD Vault, copy the code from TBD Codes, paste. Three taps.
